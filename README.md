# 微信公众号文章美化编排（Wechat Article Beautify）

> 一个 WorkBuddy 技能：把一篇写好的文章，一键套用 7 套内置行业排版模板，生成**微信公众号编辑器可直接粘贴**的成品 HTML，并支持多版本并排对比预览。

---

## ✨ 这是什么

你只管写内容，排版交给模板。给一篇 Markdown / 纯文本 / 文章正文，技能会自动把它重排成符合公众号审美、全内联样式、能直接「全选 → 粘贴」进公众号后台（或 135 / 秀米）的成品页面。

核心原则叫**「保义重排」**：

- ✅ 只改**排版呈现**（标题层级、编号徽章、加粗强调、引用块、列表、表格、配色）
- ❌ 不改**内容语义**（不增删观点、不概括缩写、不做 AI 味润色）

> 模板本身**不含示例文章**，所有文字都是简单的占位描述（「文章主标题」「此处是二级标题」「列表项 1」「表头 1」…）。套用时把占位符替换成真实内容即可，所见即所得，不会被示例内容干扰。

---

## 🎯 特性

- **7 套行业模板**：商务咨询 / 教育培训 / 金融理财 / 美食生活 / 医疗健康 / 文学情感 / 科技互联网，风格、配色、气质各异。
- **向导式交互**：启动即引导选模板，也可一键「套用所有模板」批量生成。
- **多版本对比**：所有模板套用后生成并排对比视图（375px 手机视口真机截图网格 + iframe 回退），方便挑版本。
- **公众号零适配**：全程内联样式 + `<section>` 结构，无外部 CSS / JS / class / id，粘贴进编辑器不会走样。
- **可迭代**：不满意的版本可换模板、微调组件、或整体重排，主动提示继续打磨。

## 🚀 安装（作为 WorkBuddy 技能）

**方式一：技能市场 / 导入**
在 WorkBuddy 中选择「安装技能」并导入本仓库，技能会自动注册。

**方式二：手动放置**
将本仓库内容复制到用户级技能目录：

```bash
# Windows
cp -r wechat-article-beautify %USERPROFILE%/.workbuddy/skills/wechat-article-beautify

# macOS / Linux
cp -r wechat-article-beautify ~/.workbuddy/skills/wechat-article-beautify
```

重启 / 刷新 WorkBuddy 后，对助手说「帮我美化这篇文章」「文章排版」「套模板」等即可触发。

## 🧭 使用流程（技能内部 5 步）

1. **准备**：确认已有原文（未提供则先问你要）。
2. **选模板**：一次提问让你勾选——可选「套用所有模板」，或者指定某几个（如「4,7」）。
3. **套用（单模板）**：读取对应模板骨架，把占位文字逐段替换成你的文章内容，内联样式原样保留。
4. **批量套用**：选「全部」时，对 7 个模板逐个生成独立成品。
5. **对比交付**：生成并排对比视图，挑出版本后告诉你用法，并主动问「哪个最接近预期？需要我继续打磨吗？」

### 套用时的硬性约束

- 正文**逐句保留**，不改语义；
- 模板的**颜色 / 字体 / 字号 / 间距**一律不改（除非你明确要定制）；
- 原文没有的内容（如无表格 / 代码）对应占位组件**整块删除**，成品里不留任何「此处是…」占位文字。

## 📐 占位符对照（速览）

| 模板占位文字 | 替换为 |
|---|---|
| 分类标签 | 文章分类（如：商务咨询） |
| 日期 · 阅读约 X 分钟 | 发布日期 + 阅读时长 |
| 文章主标题 | 原文标题 |
| 此处是二级 / 三级标题 | 原文 `##` / `###` 小节 |
| 此处是正文段落 | 原文段落（逐句保留） |
| 列表项 N | 原文并列要点 |
| 步骤 N | 原文有序步骤 |
| 表头 N / 行 N 单元格 | 原文表格 |
| 此处是引用内容或金句 / 出处 | 原文引用或金句 |
| 此处是代码块内容 | 原文代码（无则删除） |
| 公众号名称 / 作者名 | 你的公众号信息 |

完整规则见 [`references/template-guide.md`](references/template-guide.md)。

## 📤 成品怎么用

1. 打开生成的 HTML 成品文件；
2. 全选 `<section>` 包裹的内容；
3. 粘贴到公众号后台编辑器（或 135 / 秀米）；
4. 把头图 / 配图 / 底图的渐变占位区替换成真实图片即可发布。
