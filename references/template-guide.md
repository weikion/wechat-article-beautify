# 模板速查指南（Template Guide）

7 个微信公众号模板均为「纯占位模板」形态：全部样式内联、外层结构使用 `<section>`、无外部 CSS/JS，可直接全选复制粘贴进公众号后台或 135/秀米等编辑器。模板内不含任何示例文章内容，所有文字均为简单占位描述（如「文章主标题」「此处是二级标题」「列表项 1」「表头 1 / 行1 单元格 1」等），套用时所见即所得、不会被示例内容干扰。每个模板文件位于 `assets/templates/`，文件内含使用说明注释。

**核心用法**：套用模板时，先 Read 对应模板文件，保留每个组件（分类标签、h1、导语框、编号 h2、小节 h3、要点列表、有序步骤、配图占位、表格、对比图、分隔线、引用块、结论块、代码块、作者栏、底图）的完整内联样式，将其中的占位文字逐一替换为用户文章的真实内容。不得自创样式、不得改动颜色/字号/间距。

**统一占位符对照表**（各模板占位文字与含义的对应关系）：

| 占位文字 | 替换为 |
|---|---|
| 分类标签 | 文章所属分类（如：商务咨询 / 教育培训…） |
| 日期 · 阅读约 X 分钟 | 发布日期 + 按字数估算的阅读时长 |
| 文章主标题 | 原文 h1 标题 |
| 此处是导语摘要… | 原文首段或作者导语 |
| 此处是二级标题 | 原文 `##` 小节标题 |
| 此处是三级标题 | 原文 `###` 小节标题 |
| 此处是正文段落… | 原文段落（逐句保留） |
| 列表项 N：此处是列表项内容 | 原文并列要点 |
| 步骤 N：此处是步骤内容 | 原文有序步骤 |
| 表头 N / 行N 单元格 N | 原文表格的表头与单元格 |
| 此处是引用内容或金句 / 出处 | 原文引用或金句及出处 |
| 此处是结论内容… | 原文总结性结论 |
| 此处是代码块内容 | 原文代码（无代码则整块删除） |
| 此处是单行命令或关键参数 | 原文单行命令（无则删除该 p） |
| 公众号名称 / 作者名 / 此处是公众号简介 | 用户公众号信息 |
| 关注我们 · 此处是引导关注文案 | 底图引导语 |

## 统一结构骨架（所有模板一致）

```
<section 外层容器（模板字体族+文字底色）>
  <!-- 头部：分类标签 + 日期·阅读时长 → h1 标题 → 强调条 → 导语框（左侧竖线）→ 头图占位 -->
  <!-- 正文区：编号 h2（数字徽章+标题）→ 段落 p → 小节 h3（装饰符号+标题）→ 要点列表 / 有序步骤 / 配图占位+图注 / 表格 / 对比图 / 引用块 / 结论块 / 代码块（按需）-->
  <!-- 底部：作者卡片（头像字+名称+简介+QR占位）→ 版权行 -->
  <!-- 底图：渐变关注引导区 -->
</section>
```

注意事项：

- 1–6 的 h1/h2 用衬线字体（Noto Serif SC 族），仅 7 全程无衬线黑体，勿混淆。
- 表格：1 用蓝色表头+隔行灰底；7 用渐变表头；3 用红表头。直接照抄对应模板的 th/td 样式。
- 代码块：1 深蓝底 `#1F2329`，7 纯黑底 `#05080F`；原文无代码时整块省略，连同单行命令 p 一起删除。
- 头图/配图/底图均为渐变占位区，套用后原样保留占位并改写占位提示文字（如「头图区 · 替换为文章头图」可改为具体图片描述），用户可自行替换真实图片。
- 日期、阅读时长：日期用当天实际日期；阅读时长按中文约 400 字/分钟估算。
- 分类标签文字与作者栏信息按用户文章实际内容替换；用户未提供时询问一次，不再反复追问。
- 多余占位组件（如原文无表格/代码/对比图）必须整块删除，不要把占位文字留在成品里。

## 保义重排规则（Apply Rules）

套用模板时对原文执行「保义重排」，硬性约束：

1. **不改写**：正文段落文字逐句保留（允许仅修正明显错别字），不增删观点、不概括缩写、不做 AI 味润色。
2. **结构映射**：原文 `#`→h1；`##`→编号 h2（01/02/03…按出现顺序编号）；`###`→小节 h3；无层级标记的原文按语义切分为 h2 小节，切分不改变段落顺序。
3. **强调映射**：原文加粗句若是总结性金句→「引用块」或「结论块」（每个版本最多 1 个结论块）；并列要点→要点列表（圆点）；有先后顺序的步骤→有序步骤（数字徽章）；原文表格→模板表格；数据对比→对比图占位。
4. **组件按需取舍**：原文没有对应内容时直接省略该组件；内容多于模板组件时，组件可重复使用（如多个表格、多张配图占位）。
5. **导语**：取原文开头第一段或作者导语作导语框；原文过短（<300 字）时与用户确认是否仍套用。
6. **语义不变校验**：输出前逐节比对，确认无遗漏段落、无顺序颠倒。
